Aplikasi Web Media Pembelajaran Interaktif Bahasa Arab berbasis web (HTML5, Tailwind CSS, JavaScript) dengan fokus materi **الأسرة (Keluarga)**. Dirancang khusus untuk memfasilitasi siswa MAN, SD, MI, dan SMP dalam menguasai kosakata (Mufradat), percakapan (Hiwar), dan latihan evaluasi (Tadrib) secara interaktif.

## 🌟 Fitur Utama Aplikasi

### 1. 📖 Modul 60 Mufradat (Kosakata Dual Bahasa & Audio)
- Terdiri dari **60 Kosakata** terbagi rata ke dalam 3 Tema utama:
  - **👨‍👩‍👧‍👦 Tema 1: Keluarga (20 Mufradat)**
  - **💼 Tema 2: Profesi (20 Mufradat)**
  - **🏠 Tema 3: Benda & Rumah (20 Mufradat)**
- Dilengkapi **Audio Pengucapan Fasih (Speech Synthesis API)** dengan logat Arab (`ar-SA`).
- Disertai teks Arab berharakat, transliterasi Latin, dan terjemahan Bahasa Indonesia.
- Filter kategori visual interaktif (`Semua`, `Keluarga`, `Profesi`, `Benda & Rumah`).

### 2. 💬 Modul 3 Percakapan (Hiwar Interaktif & Diagram Silsilah)
- **Hiwar 1: صُورَةُ أُسْرَتِي (Foto Keluargaku)** — Dialog Ali & Ammar menceritakan album foto keluarga, profesi ayah (insinyur), ibu (dokter), saudara (siswa SMA), dan saudari (guru Bahasa Arab).
- **Hiwar 2: أُسْرَةُ الرَّسُولِ ﷺ (Keluarga Rasulullah ﷺ)** — Dialog Umar & Utsman menceritakan silsilah kakek, orang tua, ibu susuan, paman, bibi, serta putra & putri Rasulullah ﷺ.
  - 🌳 **Diagram Pohon Keluarga Interactive Mindmap** untuk mempermudah visualisasi silsilah Nabi Muhammad ﷺ.
- **Hiwar 3: فِي الصَّبَاحِ (Rutinitas Pagi Subuh)** — Dialog seputar azan Subuh, wudhu, tilawah Al-Qur'an, shalat subuh, jas mantel, kacamata, teh hangat, dan shalat berjamaah di masjid.
- **Mode Roleplay Dual**: Sembunyikan Pembicara 1 atau 2 untuk melatih hafalan percakapan.

### 3. 📝 Modul 60 Soal Tadrib (Latihan & Evaluasi Interaktif)
- **30 Soal Tadrib Mufradat**: Menguji penguasaan kosakata anggota keluarga, profesi, dan benda rumah.
- **30 Soal Tadrib Hiwar**: Menguji pemahaman konteks dialog, sirah Nabi Muhammad ﷺ, dan tata bahasa Arab.
- **Fitur Evaluasi Otomatis**:
  - Penilaian instan (Skor 0–100).
  - Pembahasan jawaban secara real-time.
  - Tombol reset soal dan pelacakan kemajuan (*Progress Counter*).

## 🚀 Cara Menjalankan Aplikasi

Aplikasi ini bersifat **Single File Static Web App** tanpa perlu dependensi instalasi NodeJS/npm backend.

1. Clone repositori ini:
   ```bash
   git clone https://github.com/afifmashum61-oss/Alusroh.git
   ```
2. Buka berkas `index.html` langsung di browser favorit Anda (Google Chrome, Edge, Firefox, Safari).

## 🌐 Publikasi GitHub Pages
